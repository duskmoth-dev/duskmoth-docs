# Safety and verification

- AI prepares an intent; wallet approval authorizes the action.
- Scorechain Free Sanctions checks sanctions lists only. Confirm provider coverage, quotas, and commercial-use eligibility separately.
- Helius funding-source insights can require an upgraded plan; unavailable checks must stay unknown.
- No simulation, mock fixture, connectivity check, or passing unit test proves a funded transaction succeeded.
- A source-only release is not audited, anonymity-guaranteed, or a production safety certification.
- Never share keys, signed payloads, private notes, or private financial records in issues.
- Review release checksums and source provenance before installing a package.

The application source has a separate security release gate. The dependency-free client and these guides do not remove upstream application advisories.
